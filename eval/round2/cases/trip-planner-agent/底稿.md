## 二、仓库里有什么

- prompts/ 下三个提示词：system_prompt、itinerary_planner、budget_checker。
- notebooks/demo_walkthrough.ipynb：读 sample_requests.jsonl，逐条生成行程。
- data/ 下全是手工整理的示例数据。
- 依赖写在 requirements.txt；在 Python 3.11 上跑过。
- 模型接口通过 .env 配置，.env.example 给了模板，兼容 chat completions 格式。
- 三段提示词串行调用同一个模型，中间结果用 JSON 传。

## 三、没有的东西

- 没有 Web 界面，没有 app.py，没有部署到任何地方。
- 没有外部用户，只有作者自己在 notebook 里跑。
- 没接航班、酒店的任何接口，不能查价，也不能预订。
- 没接地图服务；距离用 POI 表里的经纬度算直线距离来估。

## 四、能力边界

- 城市：只有京都、成都两份示例 POI。
- 每条 POI 字段：名称、类型、经纬度、建议游玩时长、开放时间、人均花费。
- 只测过中文请求，英文没测。
