## 二、环境与依赖

- pyproject.toml 里写的是 requires-python = ">=3.10"。
- 运行时依赖只有 click、rich。
- dev 依赖组（.[dev]）：pytest、pytest-cov、tox。
- tox.ini 配了 py310、py311、py312 三个环境。

## 三、安装方式

- 还没发布到 PyPI，目前只能 git clone 后 pip install -e . 源码安装。

## 四、命令（cli.py 里实际注册的）

- add、list、report、import 四个子命令。
- import 支持 --csv 和 --json 两种。
- 没有 export 子命令，PDF 报表没做。

## 五、存储与配置

- SQLite 单文件 ~/.ledger/ledger.db。
- 首次运行在 ~/.ledger/ 下生成 config.toml。
- 只支持单一币种，config 里一项 currency。
- 没有任何联网、同步功能，也不打算做。

## 六、测试

- 2026-09-14 本地跑 pytest：47 passed。

## 七、性能

- 2026-09-10 在一台 8 核笔记本上单次测试：导入 1 万行随机生成的 CSV，用时 2.3 秒。
