## 🌱 项目背景

每到期末周，图书馆门口总能看到排队等座的同学，而馆内却有不少座位被书本"占着"、人却不在。
据统计，全国高校图书馆在考试周的无效占座率超过 70%，每位学生平均每天要花 25 分钟找座位。

我们对 14 名在校同学做了深度访谈，归纳出三个核心痛点：

1. **找不到座**：不知道哪层还有空位，只能一层层爬楼看。
2. **占座不来**：有人一早放下书包，中午才出现。
3. **暂离被清**：去接水、上卫生间回来，座位已经被别人坐了。

项目历时半年打磨，从访谈、原型到 PRD 完整走完了一轮。
静位 SeatNow 是业内首个、也是最智能的图书馆座位预约方案。

## ✨ 核心功能

| 功能 | 说明 | 状态 |
|---|---|---|
| 🗺️ 楼层选座 | 按楼层、区域查看空位，点选即预约 | ✅ 原型已完成 |
| ⏰ 时段预约 | 可提前 1 天预约，每个时段 2 小时 | ✅ 原型已完成 |
| 📷 扫码签到 | 到座后扫桌贴二维码签到，15 分钟未签到自动释放 | ✅ 原型已完成 |
| ☕ 暂离保留 | 一键暂离，座位保留 30 分钟 | ✅ 原型已完成 |
| 🙂 人脸识别签到 | 入馆闸机刷脸即自动签到，无需扫码 | ✅ 已支持 |
| 📋 违约记录 | 累计 3 次违约暂停预约 7 天 | ✅ 原型已完成 |
| 🔔 预约提醒 | 开始前 15 分钟推送订阅消息 | 📝 PRD 已写，原型待补 |

> 选座流程控制在 3 步以内（设计目标，见 PRD 第 4 节）。

## ❓ 常见问题

**Q：支持多校区吗？**
A：当前版本只针对单个馆舍设计，多校区暂不在计划内。

**Q：违约规则可以改吗？**
A：违约次数和暂停天数在 PRD 中定义为馆方可配置项。

**Q：暂离超时会怎样？**
A：暂离超过 30 分钟未回，座位自动释放，并记一次违约。
